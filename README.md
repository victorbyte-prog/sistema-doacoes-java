# Sistema de Doações

Sistema desenvolvido em Java com o objetivo de facilitar o gerenciamento de doações, contribuindo para a organização e o apoio a projetos sociais.

O projeto aplica conceitos de programação orientada a objetos, organização de código e gerenciamento de dados, com possibilidade de integração com MySQL.

## Funcionalidades

- Gerenciamento de doações, facilitando o controle e a organização dos registros
- Menu desktop para acessar as funções do sistema
- Organização dos dados com base em conceitos de programação orientada a objetos
- Possibilidade de armazenar os dados em um banco MySQL

## Tecnologias

- Java [25]
- MySQL (para armazenamento dos dados)
